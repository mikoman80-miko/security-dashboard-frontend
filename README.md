# 🛡️ 보안 관제 대시보드 프로젝트

팀 프로젝트로 진행 중인 보안 관제 시스템의 프론트엔드 대시보드입니다.
실시간 보안 로그를 모니터링하고 시각화하여 보여줍니다.

## 🚀 사용된 기술 (Tech Stack)
- **핵심 언어:** HTML, CSS, JavaScript
- **프레임워크:** React.js
- **개발 환경:** Node.js, VSCode
- **버전 관리:** Git, GitHub

## 📝 주요 기능
1. **실시간 로그 모니터링:** API를 통해 수집된 보안 패킷 및 로그 데이터를 표(Table) 형태로 출력
2. **위험도 요약 카드:** 전체 로그 중 '위험(High)' 및 '차단' 상태의 통계를 자동 계산하여 상단에 배치
3. **데이터 새로고침:** 버튼 클릭 시 최신 보안 상태 데이터 동기화

## 👨‍💻 담당 역할 (프론트엔드)
- 전체적인 화면 UI/UX 구성 및 디자인 (CSS)
- React를 활용한 컴포넌트(Component) 설계 및 상태(State) 관리
- 가짜 JSON 데이터를 활용한 API 연동 테스트
